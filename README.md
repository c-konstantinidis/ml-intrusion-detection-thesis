# ML Intrusion Detection Thesis

Bachelor thesis project focused on detecting malicious network traffic using Machine Learning techniques and the CICIDS2017 dataset.

## Overview

This project explores the use of supervised machine learning models for Intrusion Detection Systems (IDS), aiming to classify benign and malicious traffic flows.

## Dataset

- CICIDS2017
- Network flow based features
- Multiple attack categories

## Implemented Models

- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- Multi-Layer Perceptron (MLP)

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Project Goal

To compare machine learning approaches for practical cyber threat detection and evaluate their effectiveness in IDS environments.
